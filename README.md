# sg-climate-wedges
Singapore Climate Wedges (2020 to 2050)

A quantitative index decomposition analysis framework downscaling the updated **Global Climate Stabilisation Wedges (Johnson & Staffell, 2026)** to model, quantify, and evaluate multi-sector decarbonisation pathways for **Singapore's 2050 Net-Zero target**.

---

## 📌 Overview

Achieving net-zero emissions in an alternative-energy-disadvantaged, land-constrained city-state requires a granular understanding of sector-specific mitigation capacities. This project downscales the global stabilisation wedges concept to Singapore's national context by:

1. **Downscaling the Wedge Metric:** Defining a standardized Singapore Climate Wedge (e.g., $2.0\text{–}3.0\text{ MtCO}_2\text{e/year}$ avoided by 2050).
2. **Modeling Business-As-Usual (BAU) & Abatement Triangle:** Establishing baseline emissions across five key sectors (Power, Industry, Transport, Buildings, and Waste) from 2020 to 2050.
3. **Constraint-Adjusted Strategy Screening:** Screening mitigation technologies applied in Singapore's context.
4. **Combinatorial Portfolio Simulation:** Computing the full solution space of valid multi-wedge pathways using generating functions and dynamic programming to quantify policy flexibility.
5. **Preliminary Cost Benchmarking:** Performing preliminary, literature-derived unit-cost scaling to determine order-of-magnitude financing requirements across candidate portfolios.

---

## 🚀 Key Features

* **Sectoral Decarbonisation Gap Modelling:** Quantify and project emissions to 2050 in a BAU counterfactual scenario to define Singapore's total abatement requirement.
* **Indicative Capital Cost Estimation:** Transparent linear unit-cost multiplier model evaluating levelised and capital investment requirements per wedge.
* **Singapore-Specific Boundary Scenarios:** Evaluates core territorial emissions reductions alongside voluntary supplementary wedges of emissions reductions in cross-boundary sectors.
